# DevOps/SRE Interview Cheatsheet

A comprehensive, interview-focused HTML cheatsheet for DevOps and SRE engineers. Covers Linux, Docker, Kubernetes, Azure, AWS, CI/CD, Terraform, and advanced senior DevOps topics.

## 🎯 Features

- **10 Core Subjects**: Linux, Docker, Azure, Kubernetes, CI/CD, Monitoring, AWS, Terraform & Terragrunt
- **Senior DevOps Topics**: 
  - Infrastructure & Connectivity (VNet, VPC, Networking)
  - Security & Governance (DevSecOps, Platform Security)
  - Reliability & Cost (HA/DR, Cost Optimization)
  - Data & Messaging (Kafka, Databases, API Gateway)
  - Service Delivery (Feature Flags, Service Mesh)
  - Operations & Reliability (Multi-cluster, Observability, Secrets Rotation)
  - Platform & Architecture (Platform Engineering, Multi-tenancy)

- **Interview-Ready Content**: Each topic includes "Say this in interview" guidance
- **Practical Examples**: Real-world scenarios, commands, and decision frameworks
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Fast Search**: Press `/` to search across all topics
- **No Dependencies**: Pure HTML/CSS/JavaScript—works offline

## 📱 Mobile Access

Open `interview-cheatsheet-v2_1.html` in any browser on any device:
- Desktop: Full sidebar navigation
- Mobile: Hamburger menu for easy navigation
- Search works great on mobile with `/` key

## 📚 Contents Overview

### Core Topics
- **Linux**: Troubleshooting, processes, permissions, systemd, networking
- **Docker**: Architecture, layers, images, containers, registries
- **Kubernetes**: Pod failures, networking, operators, debugging
- **Azure**: Subscriptions, resource groups, networking, IAM, compute
- **AWS**: EC2, VPCs, IAM, databases, Lambda (vs Azure comparisons)
- **CI/CD**: Pipelines, security gates, deployment strategies
- **Monitoring**: Observability, metrics, logging, tracing
- **Terraform**: State management, modules, best practices, interview questions

### Senior DevOps Topics
- Network connectivity (VNet peering, hub-and-spoke, ExpressRoute, Transit Gateway)
- High Availability & Disaster Recovery (RTO/RPO, replication, backups)
- DevSecOps (security in CI/CD, shift-left, policy enforcement)
- Kubernetes Operators, CRDs, and advanced patterns
- Multi-cluster strategies (federation, service mesh, global load balancing)
- Advanced observability (SLI/SLO/SLA, error budgets)
- Secrets rotation and certificate management
- Message queues & event streaming (Kafka, Service Bus, SQS)
- Database replication and high availability
- API Gateway & rate limiting
- Feature flags & progressive delivery
- Service mesh (Istio & Linkerd)
- Platform Engineering & Internal Developer Platforms
- Multi-tenancy & tenant isolation

1. **Read the intro line first** — Each topic starts with a summary of what to say
2. **Use in interview** — Open on your phone to quickly review before/between questions
3. **Focus on senior topics** — These are what senior engineer interviews focus on
4. **Practice out loud** — Read the "Say this in interview" sections aloud
5. **Understand tradeoffs** — Each section explains when to use vs when to avoid
